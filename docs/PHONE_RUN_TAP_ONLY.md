# NOOR — Phone test tour (tap-only version)

**This replaces the "Before we start" section of PHONE_RUN_CHECKLIST.md.**
That older checklist asked for a USB cable, Developer Options and
USB debugging. You do NOT need any of that. The assistant is sending
you one installable file (NOOR.apk); this tour starts after it is
installed. Install steps themselves are in INSTALL_ON_PHONE.md.

## Part 1 — Install (about 2 minutes)

1. Tap the NOOR.apk file the assistant sends you; save to **Download** if asked.
2. Open **Files** (or tap the download notification) → tap **NOOR.apk**.
3. If Android blocks it: tap **Settings** on the popup → turn ON
   **"Allow from this source"** → go back. (Standard for any app
   installed outside the Play Store; this is your own test build.)
4. Tap **Install** → **Open**.
5. When asked, tap **Allow** for:
   - **Notifications** — so prayer reminders can ring
   - **Location** — only used when you open Qibla

## Part 2 — The test tour (tick each one)

Do these in order. If anything fails, just tell the assistant the
step number — that exact thing gets fixed. A screenshot is
Power + Volume Down.

- [ ] **1. Open** — Splash says NOOR, then Home appears by itself.
- [ ] **2. Home prayer card** — shows today's real next prayer for Karachi, with a sensible time.
- [ ] **3. Qur'an** — Quran tab → Surah Al-Kahf: Arabic, English and Urdu all readable (no boxes). Text-size button makes all three bigger.
- [ ] **4. Sound** — Press Play: you HEAR the reciter. Pause, skip forward/back and speed all work.
- [ ] **5. Salah** — Worship tab → tap the prayers you prayed today; they stay ticked.
- [ ] **6. Tasbih** — tap the big circle; the count goes up. Undo works.
- [ ] **7. Qibla** — allow Location. Turn slowly; the needle settles in one direction (West-ish from Karachi).
- [ ] **8. Reminder with app closed (the big one)** — Reminders → Fajr ON. Swipe NOOR away completely. The reminder must RING while the app is closed.
- [ ] **9. Reminder after restart** — restart the phone, repeat step 8 once.
- [ ] **10. AI honesty check** — AI tab answers still say "Sample answers (offline)". That is correct for now.
- [ ] **11. Share a card** — pick a card → Export → Share: phone share sheet opens; send it to WhatsApp. "Save image" keeps a real picture on the phone.
- [ ] **12. Profile match** — Profile/Settings name and avatar match what Home shows.

## Part 3 — After the tour

Tell the assistant: "all passed", or the numbers that failed.
Nothing else is needed from you — no cable, no settings hunting,
no code.
