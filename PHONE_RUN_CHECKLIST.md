# NOOR — Phone run checklist (first real-device session)

You do NOT need to open any code. Everything below is tapping.
Do it in order; each step has a "✓ pass" line so we can record the
result together.

## Before we start — the easy way (NO cable, ~2 minutes)

**Preferred — install the file (Phase 15, done 2026-10-08):**
1. You will receive **NOOR.apk** (the app install file, ~164 MB).
2. Follow **INSTALL_ON_PHONE.md** tap-by-tap: tap the file →
   allow "install from this source" if asked → **Install** →
   **Open**. Allow Notifications; allow Location on the Qibla
   screen.
3. Then start the test tour below.

### Alternative — USB cable method

1. Android phone (any recent Samsung/Pixel/Xiaomi is fine).
2. Settings → About phone → tap "Build number" 7 times
   (switches on Developer options).
3. Settings → Developer options → turn ON "USB debugging".
4. Connect the phone to the computer with a USB cable; when the
   phone asks "Allow USB debugging?" tap **Allow**.

## The test tour (do each, note anything that looks wrong)

1. App opens → Splash says NOOR, then Home appears by itself
   (Enter NOOR also works). ✓ Splash OK / ✗ problem: ____
2. Home: prayer card shows today's real next prayer for Karachi.
3. Tap **Quran** tab → open Surah Al-Kahf → text appears in
   Arabic, English and Urdu (not boxes). Use the text-size button:
   all three grow.
4. Press **Play** on the audio player — you should HEAR the
   reciter. Pause, skip forward/back, change speed. ✓ Sound OK.
5. **Worship** tab → Salah Tracker: tap each prayer you prayed.
6. Tasbih: tap the big circle — count goes up; Undo works.
7. Qibla: allow Location permission. Turn slowly — the needle
   should settle pointing one direction (West-ish for Karachi).
8. **Reminder test (the big one):** Reminders → Fajr is ON.
   Note the clock time. Kill the app (swipe it away). Wait for
   Fajr time minus 15 minutes OR ask Muse to set a test in
   3 minutes. The reminder must RING while the app is closed.
   ✓ Rang with app closed / ✗ did not ring.
9. Restart the phone and repeat step 8 once (after reboot).
10. AI tab: answers must still say "Sample answers (offline)" —
    correct until the real AI server is connected.
11. Library → pick a share card → Export → **Share** → the phone
    share sheet opens with the card picture; send it to WhatsApp
    to confirm. **Save image** keeps a PNG on the phone.
12. Profile/Settings: name "AK" avatar matches Home.

## After the tour

Tell Muse any step number that failed or looked different from
your design pages — that exact screen gets fixed next. Screenshots
from the phone (power + volume-down) next to your design pages are
the final pixel-perfect judgement.
